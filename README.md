# found-million-short

A [Remotion](https://www.remotion.dev/) project for generating YouTube Shorts (1080x1920 vertical video).

## Commands

```
npm install
npm run dev      # open Remotion Studio
npm run build    # render the "Short" composition to out/
```

The main composition is `Short`, defined in `src/Root.tsx`, at 1080x1920, 30fps.
